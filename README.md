## v5.4 — إصلاح انقطاع الاتصال (Software caused connection abort)

- إعادة محاولة تلقائية **3 مرات لكل خطوة** مع تبديل ذكي بين مصادر الذكاء الاصطناعي المتاحة (provider rotation) وتهدئة زمنية بين المحاولات — لم يعد فشل بطّل واحد يوقف الفريق.
- تجاهل إعادة المحاولة فقط للأخطاء المنطقية (400/401/403/404) حتى لا تُهدر الطلبات.
- رسائل عربية ودّية لأخطاء الشبكة: 📶 انقطاع الاتصال، ⏱ مهلة طويلة، ⚠️ ضعف شبكة مؤقت.
- تقليم سياق الفريق (من 6000 إلى 3500 حرف لكل بطّل مع سقف إجمالي 14000) — ردود أسرع وموثوقية أعلى على الشبكات الضعيفة، وهو سبب رئيسي لانقطاع آخر بطّل (المستشار التنفيذي 💡) الذي يستقبل أطول سياق.

## v5.2 — مفاتيح بلا حدود ومصادر منتشرة

- **قوائم ضغط مطولة**: عليها حذف / نسخ المفتاح / فتح صفحة المفتاح لأي مصدر.

## v5.1 — بطاقة الفوز ومصادر أقوى

- **بطاقة اكتمال متوهجة**: عند إنجاز كل أبطال المهمة تظهر بطاقة فوز بتدرج نيون سماوي→بنفسجي مع إحصاءات المهمة (الهدف، عدد الأبطال، المراحل المنجزة والمتعثرة).

- **إعادة محاولة تلقائية**: عند 402/429/5xx يعيد التطبيق المحاولة حتى 3 مرات مع احترام وقت الانتظار الذي يطلبه الخادم، ثم الهبوط للمصدر التالي.
- **مصدر مجاني ثانٍ تلقائيًا**: إذا لم يوجد سوى مصدر واحد قابل للاستخدام يضاف "Pollinations Turbo (openai-fast)" تلقائيًا — فيعمل النموذجان A/B بنموذجين مختلفين حقًا.

## v5.0 — شاشة الفريق والمستقبل الداكن

# ⚡ HeroesGPT — فريق أبطال الذكاء الاصطناعي

تطبيق أندرويد **مجاني بالكامل** يحوّل فكرتك إلى مشروع منجز عبر **فريق من عشرة وكلاء AI**، كل بطل له مهنة مختلفة، ويعملون معًا كخط إنتاج متناسق — بلا اشتراكات ولا إعلانات ولا حساب.

## v4.0 — التطوير الشامل

- **قفل برمز PIN**: فعّل رمزًا من قسم الصيانة والبيانات؛ يُطلب عند كل فتح للتطبيق.
- **نسخة احتياطية واستعادة**: صدّر فريقك ومزوّديك كـ JSON وشاركه، واستعادته باللصق من أي جهاز.
- **حكم تلقائي ⚖️**: الذكاء الاصطناعي يحاكم بين A و B في المعركة ويحدّث لوحة الصدارة.
